# Security Policy

This repository contains the source for a live, production website
(amitista.com). If you find a security vulnerability, please report it
privately rather than opening a public issue or pull request — a public
report on a live site can be exploited before it can be fixed.

## Reporting a vulnerability

Email **amitistastudios@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a proof of concept is appreciated, but please don't
  run anything destructive or access data that isn't yours)
- Any relevant logs, requests, or screenshots

We aim to acknowledge reports within two working days and will keep you
updated as the issue is investigated and fixed. Please give us a reasonable
amount of time to address the issue before disclosing it publicly.

## Scope

In scope: the website, its build process, and anything that could compromise
the confidentiality, integrity, or availability of amitista.com or its users'
data.

Out of scope: findings that require physical access to a device, social
engineering, or that rely on already-compromised credentials; vulnerabilities
in third-party services we use but don't control (report those to the
vendor); missing security headers or best-practice suggestions with no
demonstrated impact.

## Supported versions

This project doesn't maintain multiple versions — only the code currently on
the default branch is supported.

There is currently no bug bounty program. We're happy to credit reporters
(with permission) once a fix ships.
